# Taiga Corgi NFT Design & Style Guide (Hypurr Inspired)

## 1. Core Visual Identity: Taiga the Corgi Girl
- **Species**: Pembroke Welsh Corgi (cute female dog).
- **Facial Features**: 
  - Large, erect triangular corgi ears (golden-tan outside, soft pink interior).
  - White stripe up the muzzle reaching between the eyes.
  - White fluffy chest/collar fur, white muzzle, black button nose.
  - Big, expressive dark kawaii eyes with soft highlights.
  - Sweet, cheerful smile / cute expressions.
- **Coat & Palette**: Warm golden-tan / honey fur with crisp white chest, paws, and muzzle highlights.

## 2. Art Style Principles (Derived from Hypurr Collection)
- **Format**: 1:1 Aspect Ratio, PFP profile avatar format.
- **Composition**: Centered 3/4 front view avatar pose (bust/half-body view), tail curving elegantly on the side if visible.
- **Line Art**: Clean, crisp dark outlines with defined line weight (cel-shaded / 2D vector anime style).
- **Lighting & Shading**: Smooth cel-shading with soft gradients, subtle ambient rim lighting (soft cyan/blue or warm golden glow along edges).
- **Background**: Clean, uncluttered minimalist background (flat solid tones, soft pastel gradients, or subtle theme-relevant pattern), ensuring max focus on Taiga.
- **Zero Text / Zero Logos**: Strictly no text, no random AI typography, no logos.

## 2. Current pipeline (v8 — FIXED BODY TEMPLATE)  ← use this
Like the real Hypurr collection, the BODY is identical on every card; only the
face/eyes/expression, outfit, accessory and background change.

Run: `python generate_nfts.py --body [--force] [NN ...]`

Two input images per card:
  1. `style_anchor/face_calm.jpg` — Taiga's face (identity + warm BROWN eyes).
  2. `style_anchor/body_template.png` (= `style_anchor/lab4/taiga_as_hypurr5.png`)
     — the MASTER body/pose/framing everyone shares.

Prompt rules (`BODY_PROMPT` in `generate_nfts.py`):
  - Reproduce image 2's exact body/pose/hand-positions/1:1 framing + crisp Hypurr
    style; keep brown eyes.
  - REMOVE the template's crown/robe/sword-charm (crown = Golden Queen ONLY).
  - Change only expression, outfit, accessory, background.
  - `SHORT{}` = deliberately low-detail outfit cues (let the model style them
    Hypurr-clean, not over-specified).
  - `EYES{}` = a distinct eye-shape + expression per card so faces vary
    (wide / narrowed / half-lidded / closed) instead of one neutral face.
  - Output is force-cropped to a perfect square on save (`_ensure_square`).

The `--lite` and standard (3-image per-ref) modes below are earlier experiments,
kept for reference.

## 2a. (legacy) per-reference anchoring (v5)
Each NFT is generated from **three** input images, which is what finally nailed
the authentic Hypurr look:
  1. `style_anchor/face_calm.jpg` — Taiga's real face (identity/markings).
  2. `style_anchor/anchor.png` — the locked CHARACTER anchor (= `style_anchor/
     lab7/scarf_h1.png`): our canonical corgi — warm **brown** sparkle-eyes, a
     **slim** face, **sharp triangular** ears, fine-line premium Hypurr rendering,
     her red polka-dot bandana.
  3. A per-card **real Hypurr NFT** from `ref hypurr converted/`, chosen so its
     pose/composition fits the theme (see `REFS` map in `generate_nfts.py`). The
     model copies its 3/4 angle, framing and rendering, but the outfit/props/bg
     are REPLACED by the theme. The red bandana is kept only when the costume
     doesn't cover the neck.

Backgrounds use the **Hypurr muted palette** (slate blue-grey, dusty teal, soft
mint, lilac, sakura, etc.), varied per card — NOT the old uniform green.

Convert new refs: `sips -s format png "ref hypurr/X.avif" --out "ref hypurr
converted/X.png"`. Regenerate one card: `python generate_nfts.py --force NN`.

## 2b. (legacy) Single-anchor Homogeneity Workflow
The collection is generated by `generate_nfts.py` (model `google/gemini-3.1-flash-image`)
using a **two-image conditioning** approach that is the key to a uniform look:

1. **Character reference** — `style_anchor/face_calm.jpg`, a tight face crop of
   Taiga (from `taiga2.jpg`). A tight crop is used on purpose: the full-body
   outdoor photos caused the model to *trace the scene* (rocks/leaves/bandana)
   instead of drawing a fresh PFP.
2. **Style anchor** — `style_anchor/anchor.png`, one locked canonical portrait
   (plain cream sweater, exact green background). It is fed as a *second*
   reference into every card so art style, line weight, shading, eye rendering,
   framing and the exact background colour stay identical across the set.
3. A hardened `BASE_STYLE` block + an explicit **REDRAW** instruction ("use the
   photo only as a likeness guide, do not trace it, replace the whole
   background") keep the output on-model.

To reproduce: `python generate_nfts.py --anchor` (mint anchor) → review → then
`python generate_nfts.py` (all cards). Regenerate one card with
`python generate_nfts.py --force NN`.

### Locked visual rules
- **Background**: uniform flat **deep forest pine-green `#1c3a2b`** with a subtle
  darker corner vignette — for ALL cards **except** Golden Queen, which uses a
  shiny dark-gold `#1a1200` halo background (its rarity signal).
- **Framing**: 1:1, centered half-body 3/4 bust, head near top, tail curling on
  one side.
- **No text, no brand logos** (explicitly: no adidas stripes / club crests on
  the soccer jersey).
